# Dayflow

[打开 Dayflow](https://lipume.github.io/Dayflow/)

1. 导入原格式的 `DAYPLAN` 口令。任务默认按计划开始时间排列，也可切换到优先级分组。点任务上的时间可调整安排。
2. 在任务上点「开始」。忘记及时开始时，可在计时条点「修改开始时间」补填。被打断时点「暂停」，可补记原因，再点「继续」或「停止」。停止计时后可单独勾选任务是否完成。
3. 选择日期，在「每日时间日志」查看执行和暂停记录。日志里的开始时间和结束时间都可补填，也可恢复点击按钮时记录的时刻。写下复盘后可点「导出 Markdown」。可把文件发给 ChatGPT，用当天的实际用时和打断情况调整次日计划。

可以暂停一项任务，再开始另一项。暂停中的任务可继续或停止，任一时刻最多一项任务在执行。刷新后可继续操作，跨午夜的用时按浏览器所在时区分到对应日期。计划、勾选、日志与复盘保存在当前浏览器，可通过 JSON 备份迁移。旧版 JSON 备份可以导入。
