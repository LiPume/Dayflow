# Dayflow

[打开 Dayflow](https://lipume.github.io/Dayflow/)

1. 导入原格式的 `DAYPLAN` 口令。任务默认按计划开始时间排列，也可切换到优先级分组。点任务上的时间可调整安排。
2. 在任务上点「开始」。被打断时点「暂停」，可补记原因，再点「继续」或「停止」。停止计时后可单独勾选任务是否完成。
3. 选择日期，在「每日时间日志」查看执行和暂停记录，写下复盘，再点「导出 Markdown」。可把文件发给 ChatGPT，用当天的实际用时和打断情况调整次日计划。

同一时间可有一个未停止的计时。刷新后可继续操作，跨午夜的用时按浏览器所在时区分到对应日期。计划、勾选、日志与复盘保存在当前浏览器，可通过 JSON 备份迁移。旧版 JSON 备份可以导入。
